\# DataBestie 🧠📊



\### Intelligent data analysis. Without the spreadsheet drama.



DataBestie is a universal AI-powered data analysis assistant built with Python and Streamlit.



It allows users to upload CSV or Excel datasets and automatically profile, clean, analyze, visualize, query, and understand their data using traditional data-analysis techniques combined with Google Gemini.



\---



\## 🚀 What DataBestie Does



DataBestie turns a raw tabular dataset into an interactive analysis workflow.
